# ADR-001：先验证身份与提交语义，不固定最终 Agent 底座

状态：研究中的暂定决定，2026-11-04。

使用 Node ESM + 固定 Playwright 1.56.1 + 系统 Chrome 独立临时 profile 搭建控制实验。理由：能直接持有真实节点、跨 frame 操作、运行受控服务端并取独立真值；避免先重写 CDP 或构建专用模型。不是对最终技术栈或最佳 Driver 的结论。

暴露 SDK 与 JSONL CLI 的最小能力：部分 DOM 观察、引用、click/fill/select、frame 生命周期、执行前身份校验、外部配置授权、持久写意图、分层回执。没有任务级自动规划、视觉模型、MCP、WebMCP、通用下载上传或完整长任务恢复，故不是完整通用 Agent 成品。

安全策略：所有动作均需宿主 grants；网页无权提供授权。任意 click 都可能产生写入，不接受模型自行填 risk=read 降权。当前 grants 是执行目标范围许可，不是完整业务语义权限系统。没有请求层外传防火墙，不能将它用于敌对页面上的真实敏感账户。

当前尚无选择最终复用/Fork 对象的充分证据。必须运行固定版本成熟底座的同任务对照，以及真实模型同条件任务、未见结构、公开环境。不能用 position-fallback 这个人为弱对照代替这些门槛。

原始副本按实验保存；日志默认不记录输入值，但 DOM 观察和截图仍可能包含页面数据，当前仅用于合成数据。保留 evidence 到本地不等于已实现通用脱敏。

# S22 下载内容验真

真实 Chrome 通过执行器点击下载苏州到货清单。宿主接收浏览器下载对象，再使用独立业务预期提供的 SHA-256 流式核对实际文件。下载文件名和动作派发回执分别留证。

| 场景 | 下载校验结果 | 判定依据 |
|---|---|---|
| 正确清单 | 已验证 | 下载字节与独立预期摘要一致 |
| 同名错误清单 | 失败 | 同名、等长，实际内容为南京到货单 |
| 响应体中途断开 | 未知 | Chrome 取消下载，文件流不可读 |
| 校验读取超限 | 失败 | 正确文件超过本次宿主设置的校验读取上限 |
| 响应体挂起 | 未知 | 500 ms 校验期限后请求 Chrome 取消。浏览器报告取消，服务端响应未完成即关闭 |

五组均发出浏览器点击，动作回执的业务目标仍为未知。文件校验采用精确字节摘要，要求可信方能预先给出摘要。大小上限作用于校验读取；超时从取得下载对象后开始计时，取消请求异步发送。下载事件前的挂起和传输字节预算仍待验证。

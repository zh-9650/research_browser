# S34 删除、发送、支付的宿主审批

执行器允许受信宿主在动作授权上配置审批范围。任一匹配的授权要求审批时，更宽泛的普通授权无法绕过该要求。审批请求绑定操作 ID、目标身份摘要和动作摘要。获批后，执行器在派发前重新核对页面、框架和目标。

| 受控操作 | Chrome 实测 | 独立后端 |
|---|---|---|
| 删除 A-417，宿主无审批器 | 要求审批，未派发 | 零请求 |
| 删除 A-417，宿主拒绝 | 审批拒绝，未派发 | 零请求 |
| 支付 P-681，等待审批时 120 元改为 990 元 | 目标失效，未派发 | 零请求 |
| 发送苏州通知，宿主批准 | 派发一次，旧操作 ID 重放被拒 | 一次发送 |

本轮为固定宿主审批策略和本地合成后端，无真实删除、发送或支付。当前覆盖宿主 SDK 接口和可观察身份，真实人工审批界面、站点侧不可见参数变更及跨进程审批仍待验证。

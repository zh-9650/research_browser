# 像素不变时的业务对象改绑

真实 Chrome 中，Canvas 始终显示“登记 A-417”。实验宿主在观察后替换内部事件绑定，使同一坐标请求登记 B-681。派发前复查的 URL 与 PNG 摘要保持一致。三组均使用固定坐标。

| 对照 | 后端结果 | 业务记录 |
|---|---|---|
| 截图校验，内部对象改绑 | 200 | 错写 B-681 |
| 后端一次性授权仅允许 A-417，内部对象改绑 | 403 | 零写入，记录错误对象尝试 |
| 后端授权 A-417，正常点击并重放 | 200、409 | 仅一次正确写入 A-417 |

夹具在后端将授权绑定到实验实例、登记入口及预期业务对象。截图校验只能确认画面是否发生变化。该后端保护依赖站点提供对象级约束，持久化、分布式并发与通用外站接入仍待验证。

## 宿主派发检查

新增受信宿主视觉写入入口。宿主提供预期业务对象和后端约束核验，坐标提议只携带位置。真实 Chrome 回归中，缺少约束时返回 `OBJECT_CONSTRAINT_REQUIRED`，后端收到零次请求；后端约束可用但截图摘要不匹配时，同样在点击前停止。摘要匹配时，后端仍负责拒绝改绑对象和重放。

该入口复用持久账本，点击前写入并同步派发意图。真实 Chrome 实测，重开账本后，相同操作 ID 即使只有派发意图、缺少回执，也会在点击前被拒绝。另用独立操作 ID 验证后端一次性授权仍拒绝重复生效。

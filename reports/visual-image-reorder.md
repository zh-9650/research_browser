# S16 图片按钮换位与旧坐标拒绝

真实 Chrome 使用两个 DOM 中无名称的按钮，业务标识只在背景图中呈现。页面视口为 560×290，设备缩放因子为 2；截图明确以 CSS 像素输出，与鼠标坐标共用尺度。模型使用 gpt-5.6-sol / low，两次调用共 36562 tokens。

| 阶段 | 坐标或变化 | 后端事实 |
|---|---|---|
| 首次模型决定 | 左侧 (152, 144) | 尚无请求 |
| 页面交换图片及对应业务对象 | 截图摘要变化，宿主拒绝旧坐标 | 零请求 |
| 重新观察并决策 | 右侧 (408, 144) | 仅正确选择 A-417 一次 |
| 独立反事实对照 | 同样换位，直接派发原坐标 | 错误选择 B-681 一次 |

对照保留了错选的真实后端记录。截图检查发生在派发前，检查和鼠标事件之间仍有时间窗口，视觉未变但业务绑定被替换也无法由截图摘要识别。此实验验证固定设备缩放下的图片按钮换位，尚未覆盖浏览器缩放动态变化、跨屏或敏感操作身份核实。
